# CodeReader 产品路线图

> 应用基线：CodeReader 1.0.0；应用 ID：`com.codereader.app`；发布 ABI：`arm64-v8a`。  
> 更新时间：2026-11-15（北京时间）。

CodeReader 面向在手机上浏览源代码和项目文档的开发者。产品优先级依次是可靠打开、快速定位、持续阅读、Markdown 文档和安全的小范围编辑。

## 已有能力

- 文件、SAF 目录、ZIP、公开 HTTPS Git、分享与内置示例统一打开。
- 完整项目索引、目录树、标签页、书签与阅读位置恢复。
- 文件内和项目搜索、搜索筛选、精确行列跳转与大文件全文扫描。
- 多编码读取、内存预算、只读分页和完整原始字节副本导出。
- 离线 Markdown、公式、流程图、本地图片与附件、目录、源码/预览同步。
- 新增文件模板、撤销/重做、替换、输入辅助、后台草稿与安全保存。
- Git 更新预览、本地修改保护和精确快进。
- 统一的 CodeReader 身份与方形、圆形、自适应、单色桌面图标。

## 近期优化

| 优先级 | 方向 | 要解决的问题 |
| --- | --- | --- |
| P0 | 大型项目性能 | 持续观测索引、文件切换、长文档滚动与内存峰值 |
| P0 | 搜索取消边界 | 限制异常超长行和复杂正则带来的单次扫描成本 |
| P1 | Markdown 阅读 | 长文档滚动时减少语义块定位计算，补齐导出最终产物验收 |
| P1 | Git 生命周期 | 错误分类、单文件 Diff、分支与版本浏览 |
| P2 | 开发者导航 | 符号大纲、TODO/FIXME、日志与堆栈导航 |
| P2 | 设备适配 | 平板、折叠屏、横屏布局与外接键盘 |

## 交付原则

每项工作都应有可独立验证的闭环，覆盖失败恢复、离线行为、性能边界与实际设备测试。功能说明和验收结果分开记录，构建成功不替代真机验证。

当前真机回归使用 Redmi Note 8 Pro；命令和结果记录在 [真机验证报告](真机验证报告.md)。发布流程见 [发布说明](releasing.md)。
